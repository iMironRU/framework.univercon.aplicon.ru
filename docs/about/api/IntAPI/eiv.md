# Единый идентификатор вуза (ЕИВ)

**ЕИВ** — номер человека в образовательной организации: присваивается каждому физическому лицу (абитуриенту,
обучающемуся, слушателю, выпускнику, сотруднику) один раз и **не меняется никогда** — ни при смене фамилии,
ни при переводе, ни при повторном поступлении. Его можно назвать по телефону, напечатать в студенческом билете,
передать во внешнюю систему вместо ФИО и паспортных данных.

ЕИВ не заменяет СНИЛС и документы: это собственный номер организации, который есть у каждого человека,
даже если других идентификаторов ещё нет (см. [одна запись о человеке](../../../students/database/index.md)).

## Формат (формат 2)

7 символов: `ГГ` `NNNN` `К`, представление для печати — `ГГ-NNNN-К`, например `26-0001-8`.

| Часть | Символы | Значение |
|---|---|---|
| `ГГ` | 2 цифры | две последние цифры года присвоения |
| `NNNN` | 4 символа алфавита Base32 Крокфорда | порядковый номер в году: от 1 до 1 048 575 |
| `К` | 1 символ того же алфавита | контрольный символ по алгоритму Дамма над полем из 32 символов |

Алфавит Base32 Крокфорда: `0123456789ABCDEFGHJKMNPQRSTVWXYZ` — без букв I, L, O, U, которые путаются с цифрами.

Контрольный символ ловит **любую одиночную ошибку** в символе и **любую перестановку соседних символов**.

## Ввод номера

Перед проверкой ввод приводится к каноническому виду, поэтому номер можно продиктовать и набрать «как получится»:

- пробелы, дефисы, точки, косые черты и подчёркивания игнорируются;
- регистр не важен;
- кириллические буквы-двойники заменяются латинскими, кириллическая «О» — цифрой 0;
- `I` и `L` читаются как 1, `O` — как 0.

`26-0001-8`, ` 26 0001 8 `, `26oo018` — один и тот же номер.

## Правила

- номер выдаётся при первой записи о человеке, в том числе при загрузке из других систем;
- присвоенный номер не меняется; номера не используются повторно, неиспользованный номер «сгорает»;
- при объединении двух записей о человеке номер присоединённой записи продолжает находить сохранённую запись;
- для пакетной загрузки номера резервируются диапазоном.

## Прежний формат (формат 1)

Номера вида `ГГNNNN` (6 цифр, без контрольного символа) остаются действительными: они хранятся как прежний
идентификатор человека, и поиск по ним работает. Новые номера выдаются только в формате 2.

## API

Сервис получения ЕИВ позволяет человеку узнать свой номер по документу, удостоверяющему личность, с подтверждением
через электронную почту. Требования к сервису:

- ответ не должен раскрывать, есть ли в базе человек с указанным документом;
- письмо отправляется только на адрес, уже известный организации;
- поиск выполняется по нормализованному номеру документа (см. [нормализацию](../../../students/database/index.md#2-идентификаторы-человека)).
