# Универкон Облако

Собственный облачный сервис, через который система получает сведения из внешних источников. Система не обращается
к сторонним поставщикам данных напрямую: у неё **одно своё API**, а источники за ним можно менять и дополнять.

## Что даёт

| Возможность | Источники | Доступ |
|---|---|---|
| Сведения об организации по ИНН: наименования, КПП, ОГРН, коды статистики, ОКВЭД, адрес, руководитель | реестр юридических лиц (через поставщиков данных) | по подписке |
| Лицензия на образовательную деятельность: номер, статус, места осуществления, уровни и программы | реестр лицензий Рособрнадзора | открытый |
| Свидетельства о государственной аккредитации с перечнем аккредитованных программ (коды ОКСО) | реестр аккредитации Рособрнадзора | открытый |
| Мониторинг изменений лицензии и аккредитации | реестры Рособрнадзора | по подписке |

## Как используется

- работа с новой базой начинается с **мастера**: вводится ИНН, проверяется наличие лицензии, и реквизиты организации,
  лицензия и аккредитация заполняются автоматически (см. [лицензирование](../../../management/LicensingOfEducationalActivities/index.md));
- аккредитованные программы сопоставляются с классификатором специальностей (ОКСО) по коду;
- сервис следит за изменениями в реестрах и сообщает о них.

## Доступ

Открытые сведения доступны без авторизации; сведения по подписке — с ключом доступа организации-подписчика.
