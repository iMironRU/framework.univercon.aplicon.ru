# Основные образовательные программы

Образовательная программа (ОП) — комплекс характеристик образования, который организация разрабатывает и утверждает
самостоятельно на основании ФГОС (ст. 2, 12 273-ФЗ). В информационной системе ОП держит **идентичность** программы,
а её содержание (учебный план, календарный график, рабочие программы, оценочные средства) живёт в **версиях**.

## Что определяет программу

| Характеристика | Смысл |
|---|---|
| Организация, подразделение | кто реализует (в том числе филиал) и какое подразделение выпускает |
| Направление подготовки / специальность | в границах лицензии |
| **Направленность (профиль)** | конкретизация содержания внутри направления; различает программы одного направления |
| Форма обучения | очная, очно-заочная, заочная — из допустимых ФГОС |
| Квалификация | по умолчанию из ФГОС; нужна для документов об образовании и раздела сайта «Образование» |
| Язык обучения | государственный язык, если иное не установлено локальным актом (ст. 14 273-ФЗ) |
| Контингент | для кого программа (например, иностранные граждане) |
| Действующая версия | версия, по которой программа реализуется сейчас |

**Направленность — справочник, а не текст.** Одна и та же направленность встречается в нескольких программах и годах,
её используют приём (конкурсные группы), сайт и отчёты. Направленность принадлежит направлению подготовки:
программе можно указать только направленность её направления.

## Версии ОПОП

Версия — снимок состава программы на дату: учебный план, календарный график, рабочие программы дисциплин и практик,
оценочные средства, программа ГИА — и ФГОС, на основании которого этот состав составлен.

Правила:

1. **Утверждённая версия не меняется.** Любое изменение компонента — это новая версия; утверждённую можно только перевести в архив.
2. **Только вперёд.** Номер версии растёт; дата начала действия новой утверждённой версии не раньше предыдущей.
3. **Новая версия — копия предыдущей.** Состав и ФГОС переносятся, дальше меняется то, что вызвало версию; у версии указывается основание
   (новый ФГОС, изменение рабочей программы, приказ).
4. **ФГОС закреплён за версией.** Смена ФГОС (новый приказ) — это новая версия ОПОП. Обучающиеся, принятые раньше, продолжают
   учиться по своей версии и своему ФГОС; нормы и проверки берутся из ФГОС той версии, по которой идёт обучение.
5. **Утверждение — событие документооборота.** Дата и документ утверждения (приказ, протокол учёного совета) фиксируются в версии,
   но не создают её: версия существует и как черновик.

ФГОС программы на дату определяется так: ФГОС действующей утверждённой версии; если версий нет — ФГОС, указанный в программе;
если не указан — последний действующий ФГОС по направлению на дату начала обучения.

## Цепочка планирования

**ОП → версия ОПОП → учебный план → рабочие программы дисциплин и практик → занятия.**
Учебный план и рабочие программы — компоненты версии; рабочая программа не владеет трудоёмкостью и формами контроля,
а берёт их из строки учебного плана.
