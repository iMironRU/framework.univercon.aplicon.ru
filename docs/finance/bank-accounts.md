# Банковские счета и квитанции

## Счета организации

Источник истины — бухгалтерия (БГУ / БП). Информационная система вуза хранит **только сведения, нужные для
договоров, квитанций и платежей**, и со временем получает их из бухгалтерии обменом.

Организация может работать на бюджетной основе (счета в казначействе) или без неё (например, организация
дополнительного образования — обычные банковские счета). Поэтому у счёта организации есть вид:

| Вид счёта | Что хранится |
|---|---|
| Банковский | номер счёта, банк (по БИК из классификатора банков), корреспондентский счёт |
| Казначейский (лицевой счёт в УФК) | номер казначейского счёта, номер лицевого счёта, ТОФК (по БИК), единый казначейский счёт (ЕКС), наименование получателя для платёжного документа («УФК по … (…, л/с …)») |

Для обоих видов: валюта, счёт цифрового рубля, КБК и ОКТМО для платных услуг, шаблон назначения платежа,
признак «закрыт».

**У вуза обычно несколько счетов** (бюджет, приносящая доход деятельность, дополнительное образование, общежитие).
Нужно правило, какой счёт подставляется в договор и квитанцию: по виду образования, подразделению, назначению.

## Счета физических лиц и контрагентов

Источник истины — информационная система вуза. Используются для **договоров** (плательщики) и **выплат**
(стипендии, возвраты).

- у одного лица может быть несколько счетов; один отмечается как **основной**, отдельно — счёт **для стипендии**;
- поддерживаются платежи из-за рубежа: IBAN, SWIFT, страна и международное наименование банка;
- поддерживается счёт цифрового рубля;
- для бюджетных заказчиков (например, целевого обучения) — казначейские реквизиты;
- реквизиты банка сохраняются в самом счёте (снимок), а не только ссылкой на классификатор:
  банк может исчезнуть из классификатора, а реквизиты нужны в документах.

**Банковские карты** физических лиц (для стипендии на карту «Мир» — национальный платёжный инструмент)
хранятся полностью и показываются по маске.

**Зарплатные проекты** (лицевой счёт обучающегося в банке зарплатного проекта для зачисления стипендии) — зона
кадровой системы. В информационной системе вуза их ведение включается функциональной опцией.

**Совпадение счёта у разных людей — алерт.** Один и тот же счёт у двух физических лиц может быть законным
(один платит за другого), но это всегда предупреждение при вводе, отметка в обеих карточках и задача
ответственному; для [поиска дублей](../students/database/index.md) это слабый сигнал, а не основание для слияния.

## Квитанции на оплату

Квитанции на оплату обучения и дополнительных услуг формируются в информационной системе вуза:

- форма ПД-4 с двумерным штрихкодом по ГОСТ Р 56042 (оплата в любом банке по QR);
- QR-код для оплаты через Систему быстрых платежей;
- реквизиты получателя — из счёта организации, подобранного по правилу; суммы — из расчётов с обучающимся.

## Совместимость с другими системами

Состав реквизитов выбран так, чтобы обмен с кадровой (ЗКГУ) и бухгалтерской (БГУ) системами ложился без
сопоставления полей: счета физических лиц и контрагентов — как в ЗКГУ, расширенные полями для иностранных и
казначейских счетов; счета организации — проекция лицевых и банковских счетов БГУ.
